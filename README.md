- Python 3.9+
- pip (مدير الحزم)
- حساب Telegram Developer
- مفتاح API من SMMCPAN

## 🚀 التثبيت السريع

### 1. استنساخ المستودع
```bash
git clone https://github.com/piko33300-dot/telegram-smm-panel-bot.git
cd telegram-smm-panel-bot
```

### 2. إنشاء بيئة افتراضية
```bash
python -m venv venv

# على Windows
venv\Scripts\activate

# على Linux/Mac
source venv/bin/activate
```

### 3. تثبيت الحزم
```bash
pip install -r requirements.txt
```

### 4. إعداد متغيرات البيئة
```bash
cp .env.example .env
```

ثم عدّل ملف `.env` وأضف:
- `TELEGRAM_BOT_TOKEN` - رمز البوت من BotFather
- `TELEGRAM_ADMIN_ID` - معرف المسؤول
- `SMMCPAN_API_KEY` - مفتاح API من SMMCPAN

### 5. تشغيل البوت
```bash
python main.py
```

## 🐛 استكشاف الأخطاء

### البوت لا يستجيب
- تأكد من صحة `TELEGRAM_BOT_TOKEN`
- تحقق من اتصالك بالإنترنت
- جرب إعادة تشغيل البوت

### لا يمكن الاتصال بـ API
- تحقق من صحة `SMMCPAN_API_KEY`
- تأكد من توفر الرصيد في الحساب
- تحقق من توفر الخدمة

### خطأ في قاعدة البيانات
- احذف ملف `smm_bot.db` وأعد التشغيل
- تأكد من أذونات الملفات
